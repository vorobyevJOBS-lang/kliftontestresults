# Интеграция EvidenceHire с hh.ru

Статус: технически возможна, но production-разработка заблокирована до выбора подтверждённой инфраструктуры в РФ и регистрации приложения hh.ru.

## Что можно синхронизировать

- OAuth работодателя по Authorization Code + PKCE; для разных регистраций работодателя — отдельные подключения.
- Активные вакансии, отклики и приглашения.
- Чаты через актуальные `/common/chats` endpoints: чтение и отправка сообщения из EvidenceHire отражаются в реальном чате hh.ru.
- Этап отклика только через разрешённые `actions[].method`, `actions[].url` и `arguments`, возвращённые API.
- Webhooks по откликам, чатам, сообщениям и смене этапов плюс периодическая сверка, потому что доставка webhook не гарантируется.

## Стоимость и права

Отдельной универсальной публичной цены «за API» нет. Обработка уже полученных откликов была открыта работодателям без отдельной API-услуги, но публикации, база резюме, контакты, холодный поиск и дополнительные лимиты зависят от купленных услуг hh.ru. После OAuth права проверяются методом `method_access`; обещать полностью бесплатную интеграцию до этой проверки нельзя.

## Безопасный MVP

1. Подтвердить российское размещение сервера, OAuth-токенов и импортированных данных либо перенести HH-коннектор и хранилище в РФ.
2. Зарегистрировать приложение на `dev.hh.ru`; модерация может занимать до 15 рабочих дней.
3. Хранить refresh tokens только зашифрованно на сервере; никогда не просить и не хранить пароль hh.ru.
4. Начать с read-only: вакансии, отклики по ним и чаты.
5. Связывать записи по `employer_id + vacancy_id + topic_id + resume_id + chat_id`, не по имени или email.
6. Добавить webhook с дедупликацией по event id и периодическую сверку.
7. Сообщения и смену этапа выполнять только после явного действия HR; для сообщений использовать UUID `idempotency_key`.
8. Передавать действия обратно в hh.ru: односторонний импорт ухудшает индекс вежливости работодателя.
9. Не включать холодный массовый экспорт и массовые сообщения: ATS работает только с откликнувшимися и приглашёнными кандидатами.
